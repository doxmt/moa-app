# Legal Pages

App Store Connect에 제출할 공개 약관 URL용 정적 문서입니다.

GitHub Pages를 사용할 경우 저장소 설정에서 Pages source를 `develop` 브랜치의 `/docs` 폴더로 지정하면 아래 URL 형태로 접근할 수 있습니다.

- 개인정보처리방침: `https://doxmt.github.io/moa-app/legal/privacy.html`
- 이용약관: `https://doxmt.github.io/moa-app/legal/terms.html`

앱 내 문구를 수정하면 `app/settings/privacy.tsx`, `app/settings/terms.tsx`와 이 HTML 문서를 함께 갱신해야 합니다.
