# 1.0 출시 전 QA 체크리스트

## 목적

Apple Developer 등록이 완료되기 전까지는 App Store 제출, TestFlight, Sign in with Apple 실기기 검증이 제한된다.
그 전에는 앱 내부 흐름과 데이터 안정성을 먼저 확인한다.

## 현재 보류 항목

Apple Developer 등록 완료 후 진행한다.

- Apple Developer 계정 등록 완료
- 개인정보처리방침 공개 URL 설정
- EAS projectId 생성 및 app.json 연결 확인
- Sign in with Apple capability 확인
- Supabase Apple provider 설정 확인
- EAS production iOS build
- TestFlight 배포
- App Store Connect 메타데이터 제출
- App Review 제출

## 공통 QA 기준

- 앱이 빈 화면으로 멈추지 않는다.
- 로딩 상태가 표시된다.
- 실패 시 토스트 또는 안내 문구가 나온다.
- 뒤로가기/탭 이동 후에도 화면 상태가 깨지지 않는다.
- 로그아웃 후 이전 사용자 데이터가 남지 않는다.
- 앱 재실행 후 세션과 화면 진입이 정상이다.

## 인증

### 카카오 로그인

- 로그인 버튼을 누르면 인증 화면이 열린다.
- 인증 성공 후 온보딩 또는 홈으로 이동한다.
- 사용자가 인증을 취소하면 로그인 화면에 머문다.
- 실패 시 에러 안내가 표시된다.

### Google 로그인

- 로그인 버튼을 누르면 인증 화면이 열린다.
- 인증 성공 후 온보딩 또는 홈으로 이동한다.
- 사용자가 인증을 취소하면 로그인 화면에 머문다.
- 실패 시 에러 안내가 표시된다.

### Apple 로그인

Apple Developer 등록 후 확인한다.

- iOS에서만 Apple 로그인 버튼이 보인다.
- Android에서는 Apple 로그인 버튼이 보이지 않는다.
- Apple 인증 성공 후 Supabase session이 생성된다.
- 사용자가 Apple 로그인을 취소하면 에러 토스트가 뜨지 않는다.
- Apple identity token이 없을 때 앱이 크래시하지 않는다.

## 온보딩

- 신규 로그인 사용자는 온보딩으로 이동한다.
- 이름 입력 후 다음 단계로 진행된다.
- 필수 입력값이 비어 있으면 저장되지 않는다.
- 온보딩 완료 후 홈으로 이동한다.
- 앱 재실행 후 온보딩으로 다시 가지 않는다.

## 홈

- 커플 미연결 상태에서 연결 안내가 보인다.
- 커플 연결 상태에서 내 닉네임과 상대 닉네임이 보인다.
- D-day가 정상 표시된다.
- 대표 사진이 있으면 표시된다.
- 사진 변경 시 권한 요청이 정상 동작한다.
- 사진 업로드 실패 시 안내가 표시된다.
- 오늘의 밸런스 게임 카드가 표시된다.
- 답변 제출 후 선택 상태가 유지된다.

## 커플 연결

- 초대 코드가 생성된다.
- 초대 코드 복사가 동작한다.
- 상대방 코드 입력으로 연결된다.
- 잘못된 코드 입력 시 안내가 표시된다.
- 이미 연결된 사용자는 중복 연결되지 않는다.

## 캘린더

- 월 이동이 정상 동작한다.
- 오늘 날짜가 정상 계산된다.
- 일정 생성이 동작한다.
- 일정 수정이 동작한다.
- 일정 삭제가 동작한다.
- 하루종일 일정과 시간 지정 일정이 각각 표시된다.
- 생일/기념일/마일스톤 가상 일정이 표시된다.
- 커플 미연결 상태에서도 화면이 깨지지 않는다.

## 질문

- 오늘의 질문이 표시된다.
- 지난 질문 목록이 표시된다.
- 답변 선택이 저장된다.
- 답변 이유 작성이 저장된다.
- 상대방 답변 상태가 정상 표시된다.
- 질문 갱신 시각 변경 후 day number가 역행하지 않는다.

## 추천

- 추천 메인 화면이 열린다.
- 룰렛 후보 추가/삭제가 동작한다.
- 후보가 부족하면 룰렛 실행이 막힌다.
- 룰렛 실행 후 결과가 표시된다.
- 사다리/뽑기 화면 진입과 뒤로가기가 정상이다.
- 긴 후보 텍스트가 UI를 깨지 않는다.

## 스토리

- 커플 연결 전 안내 화면이 표시된다.
- 사진 선택 권한 요청이 정상 동작한다.
- 카메라 권한 요청이 정상 동작한다.
- 스토리 업로드가 동작한다.
- 하루 3장 제한에 도달하면 업로드가 막힌다.
- 업로드 제한 문구가 결제/프리미엄처럼 보이지 않는다.
- 오늘 스토리가 내/상대 영역에 표시된다.
- 이전 스토리 보기가 동작한다.
- 7일 이전 스토리는 잠금 처리된다.
- 잠금 토스트가 결제 유도 문구를 포함하지 않는다.
- 스토리 캡션 수정이 동작한다.
- 스토리 삭제가 동작한다.
- 상대방 스토리 사진 저장 권한 요청이 정상 동작한다.

## 알림

- 알림 권한 요청이 정상 동작한다.
- 알림 설정 이동이 정상 동작한다.
- 알림 목록이 열린다.
- 알림이 없을 때 빈 상태가 표시된다.
- 알림 읽음 처리가 동작한다.
- 전체 읽음이 동작한다.
- 단일 삭제가 동작한다.
- 전체 삭제 확인 모달이 표시된다.
- 알림 탭 시 관련 화면으로 이동한다.

## 설정

- 내 정보 수정이 동작한다.
- 커플 정보 수정이 동작한다.
- 캘린더 아바타 변경이 동작한다.
- 질문 갱신 시각 변경이 저장된다.
- 개인정보처리방침 화면이 열린다.
- 이용약관 화면이 열린다.
- 문의하기 mailto 링크가 열린다.
- 로그아웃 후 로그인 화면으로 이동한다.
- 로그아웃 후 홈/알림 캐시가 남지 않는다.

## 계정 삭제

- 계정 삭제 화면이 열린다.
- 삭제 전 확인 단계가 표시된다.
- 취소 시 데이터가 유지된다.
- 삭제 실행 후 로그아웃된다.
- 재로그인 시 기존 데이터가 노출되지 않는다.

pnpm run lint
```

pnpm dlx eas-cli@latest submit --platform ios --profile production
```

## TestFlight 이후 추가 확인

- 실제 iPhone에서 앱 설치가 정상이다.
- Push token 등록이 정상이다.
- 실제 푸시 알림 수신이 가능하다.
- 사진 선택/촬영/저장이 실제 기기에서 정상이다.
- Apple 로그인 실기기 인증이 정상이다.
- 앱 종료 후 푸시 탭으로 진입 시 올바른 화면으로 이동한다.
